2.1 Gestión Dinámica de Prompts de IA

a13294d 28 de junio de 2026 feat(prompts-ia)
Fecha de implementación

Qué es: Nueva pantalla de configuración ubicada en Configuración › Prompts de IA (/config/prompts) que permite al superadministrador visualizar, editar y restaurar los prompts del sistema utilizados por la inteligencia artificial.

Innovación técnica clave:

  • Los prompts ahora se almacenan en la base de datos (tabla prompts_ia) con su valor predeterminado
  • Los pipelines de IA (extraer.ts, mapeo-ia.ts) leen los prompts directamente desde la base de datos con caché
  • Invalidación automática de caché al editar prompts mediante updateTag(PROMPTS_CACHE_TAG)
  • Persistencia en producción utilizando el sistema de archivos de solo lectura de Vercel
  • Catálogo centralizado de prompts en src/lib/ia/prompts-catalogo.ts

Control de acceso granular:

  • Permiso requerido: prompts:administrar (exclusivamente para Superadministrador)
  • Módulo de plataforma exclusivo para administradores
  • Entrada de menú dedicada en la interfaz de administración
  • Incluye seed de base de datos (db:seed:prompts)
Detalles de implementación

Arquitectura de la solución

  • Modelo de datos: Tabla prompts_ia con campos clave, contenido (vigente), predeterminado (valor de fábrica), actualizadoPor y actualizadoEn
  • Cache inteligente: Utiliza unstable_cache de Next.js con invalidación basada en tags para rendimiento óptimo
  • Fallback seguro: Si la BD falla, cae automáticamente al valor de fábrica del catálogo para nunca romper la IA
  • Consistencia de datos: El campo predeterminado se guarda en BD (Vercel-safe) para permitir restauraciones confiables

Flujos de trabajo soportados

  • Visualización: Los superadministradores pueden ver el contenido vigente de cada prompt y saber si coincide con el valor predeterminado
  • Edición: Modificación directa del contenido del prompt con validación y registro de auditoría
  • Restauración: Volver al valor de fábrica guardado en BD o al valor de fábrica del código si no existe fila en BD
  • Invalidación de caché: Cada cambio invalida el cache de prompts para que la IA use el nuevo texto inmediatamente
⚙️

Flexibilidad operativa

Los administradores pueden ajustar los prompts sin requerir despliegues de código, permitiendo experimentación y optimización continua

💰

Optimización de costos

Mejora en el caching reduce el consumo de tokens de IA al evitar lecturas repetidas de la misma información

🎯

Calidad consistente

Los prompts se cargan desde una fuente centralizada garantizando uniformidad en todos los usos de IA

📜

Trazabilidad completa

Historial de cambios mediante el sistema de auditoría existente para cumplimiento y revisión

2.2 Monitoreo de Consumo y Costos de IA

1ad00f6 27 de junio de 2026 feat(consumo-ia)
Fecha de implementación

Qué es: Implementación de un sistema completo para registrar y monitorear el consumo de la API de Claude (Anthropic) durante los procesos de extracción y mapeo de balances, incluyendo el cálculo detallado de costos asociados.

Detalles técnicos

Modelo de datos de consumo

Nuevo modelo Prisma ConsumoIA que registra:

  • Tokens consumidos (entrada, salida, caché de creación, caché de lectura)
  • Costos en USD y COP (con snapshot de TRM al momento del registro)
  • Modelo utilizado (ej: claude-opus-4-8)
  • Tipo de operación (extracción_tabular, extracción_pdf, mapeo_ia)
  • Información contextual (cliente, usuario, archivo procesado, NIT detectado)
  • Métricas de lote (índice de lote, cuentas por lote para mapeo por lotes)

Integración con pipelines de IA

  • Extracción de balances: Los módulos extraer.ts y mapeo-ia.ts acumulan uso de IA y lo pasan a la Server Action
  • Registro eficiente: Función registrarConsumoIA que procesa múltiples usos en una sola query BD
  • Cálculo de costos: Módulo precios.ts que convierte usage de API a USD usando tarifas oficiales de Anthropic
  • Conversión a COP: Uso de TRM oficial mediante trm.ts con cache diario y fallback durable
  • Snapshot de costos: El costo USD, TRM y costo COP se congelan al registrar para preservar históricos precisos

Seguridad y permisos

  • Nuevo permiso de auditoría auditoria:ia restringido a Superadministradores
  • Páginas dedicadas en el módulo de auditoría para visualización de consumo (/auditoria/ia)
  • Tabla detallada con paginación en memoria para rendimiento óptimo
  • Dashboard con métricas resumidas (gasto mensual, tokens consumidos, llamadas por tipo)
📊

Transparencia financiera

Visibilidad completa de los costos asociados al uso de IA para mejor toma de decisiones presupuestarias

🔍

Optimización de recursos

Identificación de patrones de consumo para optimizar uso y reducir gastos innecesarios

👥

Responsabilidad operativa

Trazabilidad completa de quién utilizó qué recursos y cuándo para auditoría interna

📈

Planificación presupuestaria

Datos históricos para forecasting preciso de gastos de IA y optimización de modelos utilizados

3.1 Fotos de Perfil de Usuario

fa84d46 25 de junio de 2026 feat(perfil, exportar)
Fecha de implementación

Qué es: Sistema completo para manejo de fotos de perfil de usuarios con almacenamiento en servicios de objetos (S3/MinIO/R2) y funcionalidad de carga masiva por cédula.

Detalles técnicos

Arquitectura de almacenamiento optimizada

  • Almacenamiento externo: Solo se guarda la clave (key) en la base de datos, el binario real en almacenamiento de objetos (S3/MinIO/R2)
  • Campo nuevo: Columna clave_foto en la tabla usuarios mediante migración 20260625000000_foto_perfil_usuario
  • API dedicada: Endpoint /api/usuarios/[id]/foto para manejo seguro de imágenes
  • Componente Avatar reutilizable: Con fallback a iniciales cuando no hay foto disponible
  • Carga masiva por lote: Administradores pueden subir ZIP con fotos nombradas por cédula para actualización eficiente

Flujos de trabajo de usuario

  • Autoservicio individual: Usuario puede subir/actualizar su foto en /perfil mediante interfaz intuitiva
  • Validación de formato: Validación de tipos de archivo y tamaños mínimos/máximos
  • Procesamiento de imágenes: Redimensionado y optimización opcional antes del almacenamiento
  • Eliminación segura: Borrado tanto de la referencia en BD como del archivo en almacenamiento de objetos
  • Integración con UI: Componente Avatar usado consistentemente en toda la aplicación

3.2 Exportación de Clientes

fa84d46 25 de junio de 2026 feat(perfil, exportar)
Fecha de implementación

Qué es: Funcionalidad para exportar la lista de clientes a formato Excel desde la sección de configuración de clientes (/config/clientes).

Detalles técnicos

Implementación de exportación

  • Endpoint dedicado: src/app/(app)/config/clientes/exportar/route.ts que maneja la generación y entrega del archivo
  • Lógica de exportación: Implementada en src/lib/export/clientes.ts con pruebas unitarias en src/lib/export/clientes.test.ts
  • Formato Excel optimizado: Utiliza bibliotecas estándar para generar archivos .xlsx compatibles con Excel, Google Sheets y LibreOffice
  • Selección de campos: Incluye todos los campos relevantes del cliente (código, nombre, NIT, tipo, sector, ERP, estado, fechas de creación/actualización)
  • Integración de permisos: Reutiliza el sistema de permisos existente para controlar quién puede exportar
  • Nombre de archivo descriptivo: Generado dinámicamente con timestamp para evitar sobrescrituras

Experiencia de usuario

  • Un clic: Botón visible en la interfaz de configuración de clientes que inicia la exportación inmediatamente
  • Notificación de éxito: Toast de confirmación al completar la exportación
  • Manejo de errores: Mensajes claros en caso de fallos durante el proceso
  • Responsividad: Funciona correctamente en dispositivos móviles y escritorio
  • Privacidad de datos: Solo exporta datos a los que el usuario tiene permiso según su rol y asignaciones

4.1 Registro de Accesos y Mejora de Auditoría

739a9ec 24 de junio de 2026 feat(auditoria, balance)
Fecha de implementación

Qué es: Mejoras significativas al sistema de auditoría incluyendo el registro detallado de accesos a la plataforma y mejoras en la estructura existente de auditoría.

Detalles técnicos

Nuevo modelo de acceso

Modelo Prisma AccessLog que registra:

  • Usuario (ID y nombre desnormalizado para historial persistente)
  • Rol del usuario en el momento del acceso
  • Ruta visitada (path) con límite de longitud para prevención de abusos
  • Tipo de evento: navegacion (visitas reales), ingreso (login exitoso), salida (logout)
  • Dirección IP del cliente (para análisis de geolocalización y detección de anomalías)
  • User Agent del navegador (para análisis de tecnologías utilizadas)
  • Marca de tiempo precisa del evento

Implementación de registro

  • Registro automático en login: En src/app/actions/auth.ts después de validación exitosa
  • Registro automático en logout: En la misma función, capturando usuario antes de borrar sesión
  • Rastreador del cliente: Componente AccessTracker que envía cada cambio de ruta vía /api/registro-acceso
  • Endpoint seguro: src/app/api/registro-acceso/route.ts que verifica sesión antes de registrar
  • Best-effort logging: Función registrarAcceso que nunca lanza excepciones que afecten la operación principal
  • Índices optimizados: Índices en createdAt, (kind, createdAt) y (userName, createdAt) para consultas eficientes del tablero

Mejoras en interfaz de auditoría

  • Nueva pestaña: «Accesos y tráfico» separada de «Acciones» para mejor organización
  • Control de acceso granular: Nuevo permiso auditoria:accesos (admin-only) para esta vista
  • Filtrado avanzado: Por rango de días, usuario específico y tipo de evento
  • Tabla detallada: Con paginación en memoria y columnas informativas (fecha, tipo, cliente, usuario, archivo, etc.)
  • Dashboard resumen: Estadísticas por tipo de operación y por cliente con barras de progreso visuales

Seguridad mejorada

Trazabilidad completa de quién accedió a qué y cuándo para detección temprana de accesos no autorizados

📋

Cumplimiento normativo

Facilita el cumplimiento de requisitos de auditoría interna y externa (SOX, GDPR, etc.)

📈

Análisis de uso

Información valiosa para optimización de experiencia de usuario basada en patrones reales de navegación
